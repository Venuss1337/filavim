# Product

## Register

product

## Users

Programmers working in a native, modal code editor. Existing README and checkpoint
reports establish keyboard-driven editing as the primary workflow.

## Product Purpose

Preserve Filavim's Rust editing engine in a responsive, lightweight GPUI desktop UI.

## Brand Personality

Restrained, precise, vivid. Cyberdream Dark is the default, with Muted, Light and Rosé Pine Moon alternatives. Preserve Agave Nerd Font Mono.

## Anti-references

No web-style dashboard, decorative panels, heavy component stack or terminal imitation.

## Design Principles

- Logical edits always precede visual effects.
- Reuse working backend and established native UI.
- Make state, focus and selection legible without excess decoration.
- Viewport work and bounded, event-driven effects keep interaction responsive.

## Accessibility & Inclusion

Keyboard access, readable text, reduced motion and an immediate effects-off setting.
Physical IME, multi-monitor DPI and accessibility tooling need manual verification.
