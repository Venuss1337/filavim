Internal family: **Agave Nerd Font Mono**. Styles: Regular (all running text and
code) and Bold (titles, the mode chip, the current line number, the wordmark). The exact Mono
variant is embedded through `include_bytes!` and loaded by GPUI/DirectWrite;
no system installation is performed. Glyph coverage/monospacing is tested.

Redistribution and embedding are permitted by SIL OFL 1.1. Retain `OFL.txt`
(the font's original license/copyright) and `NERD-FONTS-LICENSE` when shipping.
Font licensing is separate from Filavim's GPL-3.0-only application license.
