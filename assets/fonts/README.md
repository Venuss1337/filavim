# Agave Nerd Font Mono

Unmodified `AgaveNerdFontMono-Regular.ttf` from the official Nerd Fonts project:
https://github.com/ryanoasis/nerd-fonts/blob/f034eeafc0ccf79afa8dd952feb86b18e5d0469e/patched-fonts/Agave/AgaveNerdFontMono-Regular.ttf

Internal family: **Agave Nerd Font Mono**. Style: Regular. The exact Mono
variant is embedded through `include_bytes!` and loaded by GPUI/DirectWrite;
no system installation is performed. Glyph coverage/monospacing is tested.
